1. Abstract & Objectives

The Wearable AI Communication Assistant is a software-based multilingual speech-to-speech communication project that runs on a laptop. The laptop's built-in microphone captures the user's voice and the software processes it through three AI stages: Speech-to-Text (STT), Neural Machine Translation (NMT), and Text-to-Speech (TTS). The laptop screen is used as the complete user interface and laptop speakers play the translated audio, requiring no external IoT boards or wearable hardware.

Core Objectives:
  • Develop an AI-based multilingual communication application running completely on a laptop.
  • Capture spoken input using the laptop's built-in microphone.
  • Convert speech into text using Speech-to-Text (STT) engine.
  • Translate recognized text from source language into selected target language via Neural Machine Translation.
  • Convert translated text into speech using Text-to-Speech (TTS) technology.
  • Display recognized text, translated text, language options, and system status on the laptop screen.
  • Provide a simple software demonstration without ESP32, IoT modules, or external hardware.
